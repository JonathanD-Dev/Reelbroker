# ReelBroker — Script de la vidéo de démonstration (≈ 5 min)

Objectif : montrer de bout en bout, sur **deux situations contrastées** (Robert contesté sur Tesla, Amira à risque élevé mais diversifiée), plus Mateo (ESG, « donnée insuffisante »), et la **preuve AWS** (panneau de gouvernance en mode Amazon Bedrock).

## Avant de filmer (checklist)

1. **Clé Bedrock : elle expire après 12 h.** La régénérer le jour même (console AWS → Bedrock → API keys), la coller dans `.env` (`AWS_BEARER_TOKEN_BEDROCK`, `AWS_REGION=us-east-1`). Ne jamais la montrer à l'écran ni la dire. Le compte d'équipe expire lundi 16 novembre en fin de journée : filmer avant.
2. `.venv\Scripts\python scripts\check_aws.py --agents` doit afficher la chaîne complète (Robert et Tesla) sans erreur.
3. Terminal 1 : `.venv\Scripts\python scripts\serve_api.py` ; vérifier http://127.0.0.1:8000/api/health : `bedrock.connected` doit être vrai. Terminal 2 : `cd web` puis `npm run dev` ; ouvrir http://localhost:5173.
4. Les textes des 91 titres sont en cache (ils s'affichent donc tout de suite, mode Bedrock). **« Vérifier une idée » n'est pas mis en cache** : l'appel est réel et prend de l'ordre de quelques dizaines de secondes (trois agents). Le lancer une fois à blanc avant de filmer, puis couper l'attente au montage (sans cacher qu'il y a eu une attente : garder la barre de progression 2 s). **Démarrer l'API au moins une minute avant de filmer** : les requêtes envoyées pendant son préchauffage peuvent attendre environ 30 s. Le premier fil d'un nouveau profil prend environ 4 s.
5. Pas de snapshot : si l'API est arrêtée, l'interface lit `web/public/snapshot.json` (texte de secours). Vérifier le badge « Amazon Bedrock » avant de commencer.
6. L'achat est simulé dans l'application (`DIRECT_BNCD = false`, boutons « Simuler l'achat » et « Si j'achetais ») : aucun lien vers le vrai courtier. On peut le montrer sans risque.
7. Chiffres à l'écran à vérifier une fois (ils viennent du code, pas de ce script) : Robert 20 % TSLA → « En conflit avec le profil déclaré », 7 % max ; volatilité 6,0 % → 13,0 % ; plafond 7 % ; Tesla pèse 84 % du risque ; fil de Robert : 91 titres, Tesla 74e.

## Si quelque chose tourne mal pendant la prise

- Badge « Texte de secours (hors ligne) » au lieu de « Amazon Bedrock » : la clé a expiré ou l'API a été lancée sans `.env`. S'arrêter, régénérer la clé, relancer `scripts\serve_api.py`.
- L'appel « Vérifier une idée » dépasse 60 s : l'interface affiche une erreur avec un bouton de reprise ; relancer.
- Ne jamais ouvrir `.env` à l'écran.
